03 · PUBLISH

把情書更新到紀念網站

↗

GitHub Pages 是靜態網站，因此按下儲存只會保留這台裝置的草稿。要讓她掃描 QR Code 後看到你新寫的情書，還要完成以下步驟：

  1. 在上方完成情書，點「複製發布內容」。
  2. 打開你的 GitHub 儲存庫 ↗，找到 config.js 檔案，按右上角鉛筆圖示編輯。
  3. 將 config.js 原有內容全部選取並取代成剛才複製的內容，按 Commit changes 儲存。
  4. 打開紀念網站，重新整理並拆開情書，確認已更新後，再把 QR Code 卡片送給她。

如果手機無法複製程式碼，也可點「下載 config.js」，再使用 GitHub 的 Add file → Upload files 上傳並覆蓋同名檔案（依 GitHub 介面顯示為準）。不要將私人帳號密碼或 GitHub Token 貼到網站。
