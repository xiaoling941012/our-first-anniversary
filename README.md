## 1. 怎麼看

把 `index.html`、`style.css`、`script.js`、`config.js`、`editor.html`、`editor.css`、`editor.js`、`card.html` 與整個 `assets` 資料夾一起放在網站目錄即可。影片在手機上需要點擊播放（避免瀏覽器限制）。

## 2. 用「情書編輯室」自己寫信（手機/電腦適用）

這次新增 `editor.html`、`editor.css` 和 `editor.js`，**不用碰程式碼就能編輯情書**。

1. 開啟網站的 `editor.html`（上線後網址為 `https://你的使用者名稱.github.io/anniversary/editor.html`），或在電腦本機直接開 `editor.html`。
2. 輸入**稱呼、情書內文和署名**。內文空一行就會自動分成另一段，右邊/下方會即時預覽正式情書。
3. 內容會自動存在**目前裝置的瀏覽器**（localStorage）；不同手機、無痕模式、清除網站資料後，草稿可能不見。請額外下載 `config.js` 備份。
4. 按「**複製發布內容**」，登入 GitHub 儲存庫，開啟 `config.js` → 鉛筆編輯 → 全選取代 → 貼上 → **Commit changes**。
5. GitHub Pages 更新後，打開你的正式網站，點開情書確認最新文字。**僅儲存草稿或下載 `config.js` 不會更新公開網站**。

若複製功能無法使用，可用「下載 config.js」取得更新後檔案，利用 GitHub 上傳替換同名檔案。`config.js` 同時包含交往日 `2025-10-31`、生日 `2026-01-14`，編輯器輸出會保留這些資訊。

**安全提醒**：`editor.html` 沒有密碼與伺服器權限，公開部署後，即使不提供選單連結，知道網址的人仍可查看編輯畫面。但其他人無法藉由它修改公開網站，必須登入有權限的 GitHub 帳號並提交更新。勿將 GitHub 密碼、權杖寫進編輯器。GitHub Pages 是公開網站，請勿存放不願公開的情書或照片。

## 3. 用 GitHub Pages 免費發布

1. 登入 GitHub，新增一個儲存庫，例如 `anniversary`。
2. **注意隱私**：使用免費的 GitHub Pages 一般需公開儲存庫，網站和素材可被公開瀏覽。發布前應取得照片/影片人物同意。不要把敏感檔案放進去。
3. 把此資料夾裡的所有檔案和 `assets` 目錄都上傳到儲存庫根目錄。**不是上傳壓縮檔本身**。`index.html` 應位於根目錄。
4. 到儲存庫的 `Settings` → `Pages` → `Build and deployment` → `Source` 選 `Deploy from a branch`，分支選 `main`，路徑選 `/ (root)`，按 `Save`。
5. 等 GitHub Pages 建立網站後，在同一頁找到 `Visit site`。網址通常為 `https://你的使用者名稱.github.io/anniversary/`。
6. 手機實際測試照片、影片、情書開啟及連結。

官方文件：https://docs.github.com/en/pages/quickstart

## 4. 產生真正能用的 QR Code 卡片

1. **等網站上線之後**，打開 `https://你的使用者名稱.github.io/anniversary/card.html`。
2. 卡片頁面會自動把網站網址做成 QR Code，也能手動輸入網站網址。
3. 點「列印卡片」，將卡片印在 A6 卡紙上（105 × 148 mm）。
4. 交給女朋友之前，用 iPhone 相機掃描紙本 QR Code，確定能成功打開網站。

**重要**：尚未上線的網站不能產生真正可用的公開 QR Code，因此絕對不要先印示意 QR Code。

## 5. 備註

- 影片採原檔，不會自動載入大量影片內容。
- 新增的 4 張照片及原有照片已轉為 WebP 以加快手機讀取速度。
- 支援 iPhone、Android、桌面瀏覽器；對「減少動態效果」的系統設定提供相容模式。
- 音樂功能暫不加入，避免未取得授權的背景歌曲及 iPhone 自動播放限制。確定曲目後可以補上「點擊播放」按鈕。
- 此專案沒有收集訪客資訊或提交個人資料。
